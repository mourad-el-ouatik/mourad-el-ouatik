## 👨‍💻 About Me

I'm a **Cybersecurity Engineering student at ENSA Marrakech**, specializing in Cyber Defense and Embedded Telecommunications, with a strong interest in **Governance, Risk Management & Compliance (GRC)** and its connection to technical security engineering.

My approach to cybersecurity is built around a simple principle:

> Security governance should translate into measurable, technically enforceable and continuously monitored security controls.

I work across the cybersecurity lifecycle, from understanding organizational risks and assessing security requirements to designing, implementing and documenting technical security solutions.

My experience includes:

- **GRC & Risk Management:** ISO/IEC 27001, ISO/IEC 27035, NIST CSF, NIST SP 800-207 and DGSSI security requirements.
- **Security Architecture:** Zero Trust, Identity & Access Management (IAM), Privileged Access Management (PAM), RBAC and network segmentation.
- **DevSecOps:** Security integration into CI/CD pipelines, static analysis, vulnerability assessment and container security.
- **SOC & Incident Management:** SIEM, SOAR, Threat Intelligence, security monitoring and incident response.
- **AI for Cybersecurity:** Local LLM integration, RAG and AI-assisted security alert analysis.

I am particularly interested in connecting risk assessments, security policies and compliance requirements with practical technical implementations.

## 🚀 Selected Projects & Security Initiatives

### 01. Zero Trust & AI-Assisted SOC Architecture

<sub>ABSEC CYBERSÉCURITÉ · 2026</sub>

Design and deployment of a hybrid security architecture connecting governance requirements, access management, infrastructure security and security operations.

**Key contributions:**

- Translated security assessment findings from 12 SMEs into technical security requirements.
- Designed a Zero Trust architecture aligned with NIST SP 800-207.
- Deployed a 9-node Docker Swarm cluster (3 managers and 6 workers) across 5 VLANs.
- Integrated identity management, privileged access controls, secrets management and network segmentation.
- Implemented an open-source SOC workflow combining SIEM, Threat Intelligence, incident management and SOAR.
- Integrated a local LLM and RAG into the SIEM-to-SOAR workflow to assist security alert analysis.

**Technologies:** Proxmox VE, Docker Swarm, Wazuh, Zeek, Keycloak, Vault, Teleport, OpenCTI, TheHive, n8n, Ollama.

### 02. Information Security Maturity Assessment

<sub>ACADEMIC PROJECT · 2026</sub>

Security maturity assessment of Cadi Ayyad University's Information System based on ISO/IEC 27001 and ISO/IEC 27035.

**Scope:**

- Information security control assessment (ISO 27001 Annex A).
- Interviews and documentary review.
- Security gap identification.
- Risk analysis and incident management assessment.
- Preparation of a prioritized remediation roadmap and budget estimation.

### 03. DevSecOps Security Pipeline

<sub>ACADEMIC PROJECT · 2026</sub>

Implementation of security controls throughout the software delivery lifecycle for a food-surplus management platform.

**Security objectives:**

- Automated CI/CD workflows with GitHub Actions.
- Static code analysis using SonarQube.
- Container image vulnerability scanning using Trivy.
- Security testing aligned with OWASP Top 10.
- Automated security feedback and remediation assistance.

### 04. FlowScope – Network Threat Detection & Visualization

<sub>MINISTRY OF EQUIPMENT AND WATER · 2025</sub>

Development of a network security monitoring and visualization solution.

**Key contributions:**

- Deployment of Suricata IDS for network threat detection.
- Processing and monitoring of more than 5,000 security events per day.
- Integration of security data into InfluxDB.
- Development of Grafana dashboards for security monitoring and reporting.
- Alignment with organizational security requirements and ISO 27001 objectives.

**Technologies:** Suricata, Ubuntu, InfluxDB, Telegraf, Grafana, GNS3.

### 05. Secure APK Analyzer

<sub>APPLICATION SECURITY & REVERSE ENGINEERING</sub>

Development of an Android application security analysis platform combining static analysis, security rules and AI-assisted investigation.

**Technologies:** Java, Spring Boot, Python, JADX, Quark Engine.
